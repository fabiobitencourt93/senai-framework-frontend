# 🌐 Contexto da Disciplina

Os Frameworks Front-end são essenciais para o desenvolvimento de aplicações modernas.

As empresas buscam aplicações:

- ⚡ Rápidas
- 📂 Organizadas
- 🔄 Escaláveis
- 🛠️ Fáceis de manter

Além disso, a arquitetura de software melhora a comunicação entre os componentes da aplicação.

---

# 💻 O que é Front-end?

É a camada da aplicação responsável pela interação com o usuário.

Suas responsabilidades incluem:

- 🎨 Interfaces
- 📐 Layout
- 😊 Experiência do usuário (UX)
- 🔗 Comunicação com o Back-end

# 🟨 Introdução ao JavaScript

## 📌 O que é?

JavaScript é uma linguagem interpretada utilizada para adicionar interatividade às páginas Web.

## 🟨 Vanilla JS

É o JavaScript puro, sem frameworks ou bibliotecas.

## ⭐ Importância

Permite:

- 🖱️ Manipular páginas
- 🌍 Consumir APIs
- 🧠 Criar lógica de programação
- ✨ Desenvolver interfaces interativas
