# Contexto da Disciplina

O desenvolvimento Front-end tornou-se um requisito estratégico para empresas.

Atualmente, a maioria das aplicações web utiliza Frameworks Front-end para desenvolver interfaces:

- rápidas;
- organizadas;
- escaláveis;
- fáceis de manter.

Além disso, a arquitetura de software possibilita melhor integração entre os componentes da aplicação.

---

# O que é Desenvolvimento Front-end?

O Front-end é a camada da aplicação responsável pela interação direta com o usuário.

Entre suas responsabilidades estão:

- construção das interfaces;
- organização visual dos elementos;
- experiência do usuário (UX);
- comunicação com os serviços de back-end.

# Introdução ao JavaScript

## O que é?

JavaScript é uma linguagem de programação interpretada e fundamental para o desenvolvimento Front-end.

## Vanilla JS

Refere-se ao JavaScript puro, sem utilização de frameworks ou bibliotecas.

É a base para compreender tecnologias modernas.

## Importância

Permite:

- manipulação da página;
- comunicação com APIs;
- criação da lógica da interface;
- interatividade.
